Put the interactive tree inside Medium

Medium can display a supported CodePen embed. The demo below is prepared from the same files as the website.

  1. Sign in to CodePen and open a blank Pen.
  2. Click Copy demo HTML below. Replace everything in the Classic editor’s HTML panel with the copied code. Leave the CSS and JS editors empty.
  3. Test the tree in the preview, then save the Pen as public.
  4. Copy the saved Pen URL, paste it on its own line in Medium, and press Enter.

The HTML contains the demo styling and query scripts. It loads the diagram renderer from the configured public website, so the Pen needs an internet connection. Medium keeps its own article layout, and its embeds become interactive after publication.

Using the new editor with an index.html file? Open CodePenDemo.html in a text editor and copy the entire file instead. That version includes the document wrappers.

Optional automatic setup

The automatic form can fail with “Something Went Wrong” on CodePen. Use the copy instructions above if it fails. This opens a draft; it does not save or publish a Pen automatically.
